工作区代码为一个场地管理系统的 go 后端，请你现在实现文件存储服务、文件上传接口。

工作区中已经定义了 FileStorage 接口（你可以按需修改，考虑拓展性），请完成 localStorage 实现该接口：将文件储存在本地。

## 基本流程：

文件上传：先进行大小及哈希校验，完成过滤与秒传等的判断，确认接收二进制后打开io，调用 FileStorage 接口进行流式文件上传与储存，同时在数据库进行记录。

文件下载：前端请求后直接持 filetoken 在数据库检索元信息，找到对应的实现并向其请求文件io，返回给前端打开读写。

文件删除：不开放给前端，交由 GC（未实现）定期进行。

## 表现层说明：

文件上传表单：POST /api/file
- size int64 文件大小
- hash string 文件前端计算哈希
- file bin 二进制文件

上传反馈表单：
- filetoken string 生成的文件访问令牌

文件下载表单：GET /api/file/<filetoken>
- size int64 文件大小
- file bin 二进制文件

## 数据库说明：

查询：通过 file_token 查询文件所在位置。数据库不存储具体路径，而是通过 storage_type 自动确定路径（路径会通过其余信息得到）。

字段：file_hash 使用文件 sha256(HEX) 的计算结果；storage_type 用于分发请求；file_size 为文件大小（byte）；fid 为数据库自增标签，无效果；其余字段均由 FileStorage 的具体实现确定。

## localStorage 实现：

- filetoken 使用“T+SHA256(base32)”的形式（总计60位）。其中，T的计算方法为将当前UNIX时间进行字母表映射（使用base32字符集）得到的8位字符（不足前导0补齐）。
- storage_type 取固定值 1
- 文件落盘位置为设置的根目录下一层目录，目录名取T部分前四位，文件名等同 file_token。也就是说，该实现每过约 12 天（32^4秒）就会将文件保存到新的文件夹。
